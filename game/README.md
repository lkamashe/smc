# جزيرتنا الصامتة — النسخة الأولى (Prototype)

نسخة أولى قابلة للتجربة من اللعبة، حسب `GAME_DESIGN.md` بجذر المستودع. مبنية
بـ Three.js (رسم ثلاثي الأبعاد) + Firebase Realtime Database (مزامنة اللاعبين
بالوقت الحقيقي) — بدون أي عملية بناء (build step)، مجرد ملفات HTML/CSS/JS.

## شو موجود بهاي النسخة

- دخول الاثنين لنفس الجزيرة عبر رابط مشترك.
- شخصيتين (شب وبنت) بكنزات مكتوب عليها "حبيب ريم" / "حبيبة علي".
- قائمة تجهيز (خشب + سنارة) مشتركة بين اللاعبين.
- بناء حيط واحد سوا (تجربة التعاون).
- صيد سمكة وإشعالها بالنار.
- حركة بأزرار افتراضية (D-pad) تشتغل باللمس والماوس، وبأسهم الكيبورد للراحة.
- حفظ الحالة بين الجلسات (Firebase) — نفس الرابط بيرجع يورّي نفس البيت والحالة.

## خطوات الإعداد (مرة وحدة بس)

1. روح لـ [console.firebase.google.com](https://console.firebase.google.com)
   وسوي مشروع جديد (مجاني).
2. من داخل المشروع: أضف "تطبيق ويب" (</> Web app)، وانسخ كائن الإعداد
   `firebaseConfig` يلي بيطلعلك.
3. من القائمة الجانبية: **Build → Realtime Database → Create Database**،
   واختار وضع البداية (Test mode) — بس للنسخة الأولى، لازم لاحقاً نضيف قواعد
   حماية حقيقية قبل ما نعتمد عليها بشكل دائم.
4. افتح ملف `firebase-config.js` بهاد المجلد، واستبدل القيم الوهمية بالقيم يلي
   نسختها من مشروعك.

## تشغيل اللعبة محلياً (للتجربة عندك)

من جوا هاد المجلد (`game/`):

```bash
python3 -m http.server 8080
```

وبعدين افتح `http://localhost:8080` بالمتصفح.

## تجربتها سوا (أنت وصاحبتك)

هاي النسخة لسا محلية عندك بس. حتى تصير قابلة للمشاركة فعلياً بين لبنان
والسويد، لازم نستضيفها على رابط عام (مثلاً GitHub Pages أو Netlify مجاناً) —
هاي الخطوة الجاية بعد ما نتأكد إنها شغالة تمام محلياً. أول واحد/ة يفتح الرابط
بيتولّد كود جزيرة عشوائي بآخر الرابط
(`?island=xxxxxx`)، ولازم يبعت نفس الرابط الكامل للتاني/ة حتى يدخلوا لنفس
الجزيرة.

## ملاحظات وتبسيطات مقصودة بهاي النسخة (تنحل بمراحل جاية)

- السنارة تُسحب من مخزون مشترك بحد أقصى قطعتين، وما في طريقة "ترجيعها"
  للمخزون بعد — تفصيلة صغيرة رح نضيفها لاحقاً.
- حجم الجزيرة وسرعة المشي (`ISLAND_RADIUS` و`PLAYER_SPEED` بأول ملف
  `main.js`) قيم مبدئية سهلة التعديل لضبط الإحساس المطلوب (~3 دقايق مشي من
  طرف لطرف).
- قواعد أمان Firebase لسا بوضع "Test mode" (مفتوحة) — قبل ما تصير اللعبة
  عامة أو دائمة، لازم نضيف قواعد تمنع أي حدا غريب من العبث بالبيانات.
